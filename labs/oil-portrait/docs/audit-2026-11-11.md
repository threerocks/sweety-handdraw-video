# 绘画引擎盘点（2026-11-11）

用户反馈：油画的感觉还行，但笔画缺轻重、深浅、不规则和自然感；绘制过程约 60 分，局部不完整、线条断断续续；素描和动漫有绘制感，但像「擦出来的」。要求：先把油画、素描、动漫三种做到极致，引擎分开设计，其他类型靠后。

这份文档是动手前的盘点：现状、问题、方向。依据是 s7 三部成片的逐步截帧和代码。流行风格和审美部分是我的判断，没有做外部数据调研。

## 一、现状

| 画法 | 代码 | 成片 | 状态 |
|---|---|---|---|
| 油画 v4.2 | `paint.py` `planes.py` | s4 / s6 / s7 各一部，约 2 分钟 | 五种风格预设，默认「块面写生」 |
| 素描 v1 | `sketch.py` `media.py` | s7 一部，119 s | 第一版 |
| 动漫 v1 | `anime.py` `media.py` | s7 一部，118 s | 第一版 |
| 成片 | `film.py` | 三种共用：手、镜头、步骤标签、节奏、封面 | 按 `kind` 分支 |

三种画法共用一条路线：图像模型先画一幅和照片对齐的「目标画」，引擎一笔一笔画到那幅画。这条路线保证了成品好看，也是下面两个共同问题的来源。

## 二、共同问题

### 1. 笔画是「窗口」，不是「笔」

素描和动漫的每一笔，落在纸上的颜色是逐像素从目标画里取的（素描：`min(纸上, 色调图)`；动漫：按形状蒙版裁切的扫描线）。笔扫过哪里，哪里就露出成品，笔本身没有形状、没有深浅。这就是「擦出来」的来源。

- 素描头发：一片黑底加白色纸纹点，看不到一根排线。
- 素描的脸：从「铺大关系」到「深入」一直是斑驳的白块，像刮刮卡。
- 动漫上色：来回扫描线把色块「擦」出来，头发填到一半是参差的白缝。

真人的一笔只有一种深浅或一个颜色，画面是很多笔叠出来的。

### 2. 覆盖是「哪里差补哪里」

规划的逻辑是：比较画布和目标，在差得多的地方落笔，再按颜色或就近排序。结果：

- 画到一半到处是洞（油画脸部块面中间留一块空白，旁边散着几笔）。
- 最后要靠「补缝」那一遍收拾，真人不会这样画。
- 线条被拆成一截一截，素描的五官辅助线是虚线。

真人是成片推进的：一个形体从一边画到另一边，手离开时这一块是完整的。

### 3. 分区蒙版硬切

油画的块面笔触被分区图逐像素裁切，脸、头发、背景的轮廓成了锯齿台阶，背景是一块块方印。

### 4. 笔触没有个体差异

油画块面笔触是直线、方头、压力固定（0.85/0.7）、抖动为 0。一遍里每一笔的分量几乎一样，没有重笔和轻扫的对比，没有干湿变化。

## 三、各画法的问题和方向

### 油画

| 问题 | 方向 |
|---|---|
| 笔触又直又匀 | 每笔有自己的压力和含色量；顺形体微弯；笔宽沿途变化；收笔干擦；叠压处拖带湿颜料 |
| 轮廓锯齿 | 笔触沿轮廓切边，或自然收笔；蒙版平滑 |
| 脸部散点、留洞 | 先暗部连成片，再中间调接上，最后亮部；每一笔挨着已画的部分生长 |
| 起稿线零碎 | 长轮廓线一笔画完 |
| 成品略像色块海报 | 块面内的微妙色彩变化、虚实边缘、亮部厚涂、几笔决定性的点缀 |

顺序沿用用户给的参考视频：起稿 → 脸 → 头发 → 五官 → 衣服 → 背景 → 特写深入 → 签名。

### 素描

| 问题 | 方向 |
|---|---|
| 像刮刮卡 | 一笔 = 一个铅笔型号 + 一条压力曲线，石墨累加变深，不再逐像素对目标取值 |
| 头发死黑一片 | 先用铅笔侧锋顺发流铺大色调，揉擦，再用尖笔画深色发丝，橡皮擦出光泽 |
| 没有起形 | 长直线切形、比例辅助线，再修轮廓 |
| 五官最后才出现 | 五官的深色早早定下，和整体一轮一轮推进 |
| 成品看不到排线 | 保留可见的排线肌理，交叉排线换角度 |
| 纸纹像椒盐噪点 | 细腻的颗粒，重压时填实 |

成品不再要求和目标画逐像素一致，要求是：是一幅好看的铅笔画，人像不走样。

### 动漫

| 问题 | 方向 |
|---|---|
| 上色像擦 | 封闭区域用油漆桶：点一下，颜色从落点漫开；不封闭的先沿边界勾一笔再填 |
| 阴影是扫出来的 | 笔先沿阴影边界走一圈，再填内部；小形状一笔点上 |
| 线稿零碎、等粗 | 每根线一笔画完，有入笔、加重、出锋；按脸 → 五官 → 头发 → 衣服 → 背景的顺序 |
| 草稿只是淡线 | 先画头部椭圆、十字辅助线、大形，再画细草稿 |
| 缺少收尾 | 眼睛高光、边缘光、整体调色一闪 |

平涂本来就是一个颜色，所以动漫成品可以和目标画很接近。

## 四、从观众和流行形式的角度

以下是我的判断。

- **过程视频好看的三个点**：开头几秒看得出在画什么；中段有「质变」的时刻（素描揉擦后忽然柔和、动漫隐藏草稿、一桶颜色倒满）；结尾有点睛和落款。现在三部片子都有结尾，中段的质变不够干脆。
- **素描**：短视频里受欢迎的是写实铅笔人像，排线清楚、眼睛先出神。全程灰蒙蒙的过程没有看点。
- **动漫**：平板绘画的录屏已经是一种固定的观看习惯：线稿利落、油漆桶填色、剪贴蒙版上阴影、最后加光效。越接近这个习惯越可信。
- **油画**：直接画法的看点是「一笔一个面」的果断，和厚颜料的质感。轻重对比和厚涂的反光比细节更重要。
- **竖屏**：1280×1920 合适。特写镜头是留住观众的手段，三种画法都应该在最好看的那一步推近。

## 五、技术上还能用的

- **图像模型**：目标画、线稿、分区图、手的素材都来自图像模型，这部分已经用上。还可以让它画「中间状态」（比如只有大色调的素描），给引擎的分层提供更可信的目标，这次先不做。
- **自动标注**：五官和眼睛的位置现在是人工标的，是量产的最大障碍。可以用人脸关键点模型自动标，三种画法稳定后做。
- **笔的物理**：这次的重点。石墨累加、颜料含量和拖带、数位笔压感，都是已知的做法，不需要新技术，需要的是把每种介质单独做对。

## 六、做法

1. 三种画法分开重做，各自一条线，互不依赖。共用的只有成片层（手、镜头、标签）。
2. 每种都用 s7 出新片，和旧片在相同步骤上对比，证据留在 `output/paint/evidence-*-20261111/`。
3. 验收看五条：没有「窗口」感；手离开时这一块没有洞；线是连续的；看得出轻重和不规则；成品好看且人像不走样。
4. 三种稳定后再做：自动标注、彩铅（素描加色）、水彩、工笔。
