## 动漫插画 v2：像在平板上画（2026-11-11）

第一版的上色是「一排排扫描线，被色块的形状裁出来」，每一笔都在把成品的形状擦出来；线稿零碎，粗细一样。v2 把每一步改成插画师真的会做的动作：**一笔要么本身就是那个形状（一根线、一缕高光、一个点），要么沿着形状的边走，要么填一个边已经画好的形状；油漆桶从点下去的地方漫开。**

| 步骤 | 做什么 |
|---|---|
| 草稿 | 先起形：头的椭圆绕两圈、中线、眼线、鼻和嘴的位置、头发和肩的大轮廓；再画浅蓝色草稿线。单独一层 |
| 线稿 | 每根线一笔画完，按人的顺序：脸的轮廓 → 眼睛（先上眼线，镜头推近，最后几笔按真速）→ 鼻、嘴 → 头发外轮廓 → 发束从左到右 → 衣服。线朝下或朝右拉，起笔、收笔处变细；接在别的线上的一端不变细 |
| 平涂 | 草稿层隐藏。线稿围住的区域用油漆桶点一下，颜色从落点漫开（几帧）；没被线围住的边（嘴唇和皮肤之间）先用这个颜色的笔沿边画一道，再点油漆桶。小块用笔涂。顺序：皮肤 → 头发 → 衣服 → 背景，一块画完再画下一块。眼睛先空着 |
| 阴影、高光 | 赛璐璐色块，剪贴在底色上。笔先沿着色块的自由边（和底色交界的那条边）走一遍，里面小的来回涂满，大的点油漆桶；细长的形状（头发的光泽、暗缝）顺着走向一笔画出 |
| 渐变 | 喷枪大笔慢扫：背景、头发、衣服、皮肤（腮红）各扫一两遍，从大笔到小笔 |
| 眼睛 | 镜头推近，一只画完再画另一只：眼白、虹膜底色、瞳孔和上深下浅的暗部，最后在线稿上面一层点高光 |
| 调色 | 手到面板上拖「调色」滑块，整幅画缓缓变到成品：线稿染成旁边的颜色并变细，加一层柔光 |
| 签名 | 最上面一层 |

做法：

- **拆开成品**（`take_apart`）：每个分区（皮肤、头发、眼睛、衣服、背景）按色相聚成几种材质，每种材质是一个平涂底色；材质内部再按明暗分出色块。**边缘是软的色块不是赛璐璐**（腮红、光晕、被分色切出来的渐变台阶）：在成品里量它自由边上的颜色梯度，低于阈值就不画成色块，留给喷枪。四周都是软边的「材质」（腮红）并回周围的材质。头发只有一个底色（最多的那个深色），亮的发束全在「高光」那一步画。
- **线稿**（`with_clean_lines`、`ink_lines`）：人物用图像模型从成品画出的干净线稿（和成品对齐），虹膜里用成品自己的细线；头发内部不再用滤波找到的「线」（那是高光之间的缝，描出来是一排碎点），那些暗缝留在颜色里，在阴影那步顺着头发画。背景没有线稿，背景是画出来的、虚的。线稿层的覆盖率来自线稿本身，所以粗细有变化；笔的宽度在起收笔处收细。
- **形状怎么画**（`paint_shape`）：最深处不到 5.5 px 的细形状，沿骨架一笔（再小就点一下）；其余的先沿自由边画（边在形状里侧一个笔宽，笔的外沿就是形状的边），再填：小于阈值的来回涂（一笔不抬），涂不到的角落补一下油漆桶；大的直接油漆桶。
- **油漆桶和调色在成片里**：`media.bucket` 的笔画按「离落点的距离」显现，所以成片里是一圈漫开的颜色，手停在落点；`media.adjust` 是最上面一层整幅淡入成品，手在面板的滑块上拖。两者都通过笔画自带的 `flood`、`seconds`、`hold`、`solo` 交给 `film.py`，油画和素描的笔画没有这些键，行为不变。
- **剪贴蒙版**：笔画的 `clip=[标签图, 编号]`，标签图（`label-flat.npy`、`label-shade.npy`）一张图存所有形状，不再每个形状存一张 PNG；边缘做了抗锯齿并向外长半个像素，相邻两块之间不漏白缝。
- **面板**：当前颜色、最近用过的颜色、四个图层（正在画的那层有框，草稿隐藏后变灰）、调色滑块。

```bash
$PY anime.py TARGET.png ROUGH_SKETCH.png AREAS.png OUT FOCUS EYES '["Leo 2026", [850, 46, 220, 66]]' \
    --photo PHOTO.png --face '[cx, cy, rx, ry]' --lineart LINEART.png
$PY film.py OUT
```

数字（s7）见 `output/paint/evidence-anime-v2-20261111/README.md`。

局限：

- 调色之前的画面和成品还有差距（s7 各区平均色差 0.015–0.02，线稿处 0.05）：线稿比成品粗、深，细的渐变没有追到底，这些都在「调色」那 2.5 秒里补齐。花纹复杂的衣服（s4 的蕾丝裙）差距更大（衣服 0.05），调色那一下看得出花纹变细。
- 色块的边来自对成品的分色，局部有锯齿状的小起伏，不如人画的弧线顺。
- 眼睛、五官的位置仍要在动漫成品图上手工标。
