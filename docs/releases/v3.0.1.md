# v3.0.1

用户看 3.0 宣传片时发现：上色后的每一块颜色都有一条条斜向的笔道，不纯净。人物的脸和衣服、天空、草地、桌面，任何图都有。这一版修掉它。

## 上色不再有条纹

**原因**：3.0.0 的画材质感（`drawing.texture`）默认把马克笔设为 `layered`。它在**完成色**上按真实笔头宽度叠一层笔道明暗，两道重叠处深约 9%，笔道边缘略积色。发布前的评估只量了平均色差（ΔE 1.1–2.1），没有量“看起来是不是一条条的”。实际成片里：

- 每张插画 87%–93% 的上色像素被笔道改变了 2 个灰度以上；
- 明暗在 −8%～+6% 之间，排成斜向条纹，铺满整张图；
- 大块平涂（天空、草地、衣服）最明显。

**现在**：

- 默认（`"texture": true` 或不写）是**压感墨线 + 平涂马克笔**：完成色与原图逐像素一致。
- 上色过程不变：刚落下的一笔是湿的、带一点毡头纹，约 0.3 秒或下一笔叠上时变实。这只是过程，不留在完成图上。
- 叠涂笔道保留为选项，只有写明 `"texture": {"marker": "layered"}` 才启用。
- `"texture": false` 仍是 2.x 的匀速针管笔；墨线压感不变。

## 验证

- **前后对比**：3.0 宣传片的三张插画，在修复前后同一时刻取帧比较。
  - 修复前，87%–93% 的上色像素被笔道改变；
  - 修复后，可与原图逐像素对齐的那张，上色像素 100% 与原图相同。
- **测试**：
  - 新增：默认设置的完成图在墨线以外与原图逐像素相等、没有笔道；
  - `layered` 的容差测试改为显式开启后再测；
  - 全套 399 项通过（1 项平台用例跳过）。
- **重新出片**：宣传片和三部样片（科普、历史、Git 教程）用同一份素材、口播和编排重新出片。工程检查、声音门禁与字幕同步都通过，字幕最大偏差 0.06–0.14 秒。

以上是工程检查。连续观感与听感需要人工观看和试听。

## 升级

- 没写 `drawing.texture` 的任务，重新 `build` 后完成色变为平涂。引擎代码变了，素材缓存会自动失效，不用手动清。
- 想保留 3.0.0 的叠涂效果，在 `job.json` 的 `drawing` 里写 `"texture": {"marker": "layered"}`。
