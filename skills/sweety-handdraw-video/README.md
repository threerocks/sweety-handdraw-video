# sweety-handdraw-video

安装一个 Skill，按主题或文章制作完整手绘讲解视频。当前版本：v3.0.0。

- 使用入口：[SKILL.md](SKILL.md)
- 项目说明、安装与样片：[GitHub README](https://github.com/threerocks/sweety-handdraw-video)
- 开始时的可选设置：[配置类型、比例、风格、声音与字幕](references/production-options.md)
- 编写任务：[运行格式](references/runtime-contract.md)
- 字幕与收尾：[模型设计规则](references/subtitle-design.md)
- 内置依赖和冲突处理：[依赖路由](references/dependencies.md)

旁白以本地为主：已安装并明确配置的 VoxCPM2，或兼容的本机 VoiceStudio 服务；火山豆包、Gemini TTS 只在用户配置了自己的密钥并选择时使用；已核对的导出音频可以离线复用。音色目录与试听见[本地声音运行](references/local-runtime.md)。生成新图片还需宿主的图像工具（Claude Code 需接入生图工具 / MCP 或使用用户提供的插画）；Python、fontTools 与 FFmpeg 负责本地合成，图片隐私清理为纯 Python。支持 macOS 与 Linux，`scripts/setup.sh` 一次装好运行环境。内置的参考指南不需要另行安装为 Skills。

### v3.0.0：线稿先行、像人一样画，收官修复

- 先出线稿再上色；笔先起形、按模块描线、橡皮擦掉起形，再按马克笔由浅到深上色；墨线压感与马克笔叠色质感（`drawing.texture`）。
- 水印每页自动挑空处；旁白在封面渐隐时开口；页头整字逐个出现；框内按词断行；结尾成图停留 2.5 秒。
- 制作工具包：一部片只写数据（`film_kit.py`、`art_pipeline.py`、`codex_image.py`、`cover.py`）；读法与写法分开（`narration.say`）。
- 详见 [v3.0.0 发布记录](https://github.com/threerocks/sweety-handdraw-video/blob/main/docs/releases/v3.0.0.md)。更新后读取本目录 `VERSION`，应为 `3.0.0`。

### v2.0.2：笔不在画面外写字，句尾干净

- **取景检查**（`scripts/framing.py`，build 自动运行）：
  - 每个正在写或画的元素每 0.25 秒检查一次，板上动效检查它出场的过程，看是否在画面里、是否压到字幕。
  - 不在画面里时，会试几种修法：镜头等笔写完再动，或补一个取景（平移一点、居中、拉远到两样都装下），保留整页效果最好的那个。笔在画面外写字最优先解决。
  - 开页取景不再被推迟；后面的镜头仍按原来对应的台词时间走。
  - 实在修不了的会在 build 警告里写明，留给版式处理。
- **句尾**：每句按最后一个字后的静音定结尾，去掉模型多念出的声音，并统一淡出；句子被截断时判为失败并重新生成。`narration_master.py rebuild JOB` 用已有分段重新拼母带，不重新合成。
- **大标题轮流出场**：同一位置的两条大标题，前一条先退场，不会被连读成一句。
- 详见 [v2.0.2 发布记录](https://github.com/threerocks/sweety-handdraw-video/blob/main/docs/releases/v2.0.2.md)。更新后读取本目录 `VERSION`，应为 `2.0.2`。

### v2.0.1：纵深、物理、三维、公式和声音，画大不再画慢

- **新能力**：视差 `depth` 与希区柯克变焦 `move: dolly_zoom`；`physics`（matter-js：倒入、多米诺、撞塌、弹跳）；`spin3d`（Zdog：盒子、硬币、易拉罐、宝石等，墨线外轮廓）；`formula`（MathJax：逐字描轮廓再填实，可圈出一部分）；直线和箭头有笔压；转场和点睛处有合成音效（`audio.sfx`）。
- **修复 2.0.0 的 9 个问题**：
  - 笔画和时长在不超过 720 px 的规划尺寸上计算，大图按显示尺寸清晰渲染；
  - `image_gate.py` 生图后几秒内查出透明窟窿、光晕和超时，并给出提示词修改；
  - 部位可写方框，`part_grid.py` 给出网格和色块编号；
  - 动效出现时笔尖先描一遍，大字默认手写体，进度圆环改为手绘；
  - 故事板检查认得写了 `visual` 的动效层；
  - 改镜头、转场或动效层时素材从缓存复用；
  - 自动镜头不再切掉已写好的标题。
- 详见 [v2.0.1 发布记录](https://github.com/threerocks/sweety-handdraw-video/blob/main/docs/releases/v2.0.1.md)。

### v2.0.0：像人一样上色，镜头、转场和动效成体系（随 v2.0.1 首次公开）

- **上色 v4**：上色跟着画面自己的闭合区域走，模型画的部件方框不再把一块颜色切成矩形（6 张测试图被切开的颜色面积 28–87% → 0–0.9%）；先沿内侧描边，再斜向排笔，刚涂上的是带毡头纹理的湿笔触，随后干透；窗口紧时退回最快的涂法，最短时长不增加。
- **镜头 v3**：命名运镜 `move`（cut / push_in / pull_out / pan / drift / hop / whip / snap / slam），对数缩放，`hop` 途中拉远，`impact` 到位震动；自动镜头每页轮换静止、慢推、跟随笔尖；build 按密度规则提示镜头过度。
- **转场 22 种**：翻页四个方向、撕纸、毛刷刷出、墨晕、墨渍光圈、橡皮擦、立方体、拼砖、碎片、闪白等；章节自动用翻页、板擦、撕纸做招牌。
- **网页动效层**：`kinetic_title` 新增 slam、scramble、word_by_word；新配方 `morph`（形状接力）、`rough_chart`（柱、线、饼、点阵、正字计数、时间线）、`map_route`（转动地球或平面地图上的航线，只画海岸线）。需要 `setup.sh --web-motion`。
- **给模型的卡组**：[运镜、转场与动效目录](references/motion-catalog.md)，每张卡写明适合与不适合，附拒绝清单和常用组合。
- **许可**：花叔仓库里不在 MIT 授权内的角色帧不再随包分发；第三方库许可见 `assets/web-motion/THIRD_PARTY_NOTICES.md`。

### v1.5.0：有条理的干净线稿、更大的图、像样的声音和镜头

- **draw-v3 绘制引擎**：只描真实墨线（深色填充、夜空、青色屏幕不再以噪点提前出现）；复杂画面按对象逐个画完，对象内先外轮廓再长出内部线；时长跟随图幅，约每秒 5 笔，同一张图放大到 720px 宽最少约 10 秒（draw-v2 约 20–32 秒）。
- **版式与指标**：`layout_plan.py` 给出 9:16 平台安全区和版式落位，并实测指定尺寸的最少绘制时间；build 实测开场第一个有效画面（超过 4 秒拒绝）、最长无变化时长和底部界面遮挡。
- **字幕**：按词断行，不切词、不让标点独占一行；竖屏单行、字号 52px，位于平台底部界面之上；可高亮关键词和数字。
- **声音**：默认笔尖音效，可选内置合成配乐；校验仍逐样本证明旁白未被改动。
- **镜头与动作**：大画板 zoom 最高 3 倍仍清晰，可逐个推近再拉远；转场新增 wipe、zoom 和板擦 erase；`emphasis` 强调动作；`arrow`、`bar_chart`、`counter`。
- **生产**：多进程并行渲染；本机素材库 `asset_library.py`；`language` 切换识别语言，语速按音节计。

### v1.4.1：发布入口与画面丰富度

- 版本说明、固定下载链接、安装包与标签一致，提供整包与逐文件 SHA-256 校验。更新后读取本目录 `VERSION`，应为 `1.4.1`。

### v1.4：原生选项、竖屏默认、导演密度

- **原生选项，不弹网页。** 先选配置类型：模型推理（默认）或主动选择。主动路径只问比例 → 风格（文字列表，无预览）→ 声音 → 字幕；兼容 Claude Code / Codex / TTY。
- **默认 2:3（1280×1920，2.0 起）**，另有 9:16、3:4、16:9、4:3、3:2 与自定义。
- **风格默认模型推理**，目录为软参考、不约束模型；揭示仍须用户明确接受。
- **presentation.mode 导演密度**：绘本稀疏 / 科普密集 / 板书累积等，由模型推断，lint 强制执行。
- **拟人绘制**：部位切换短暂停顿；线+色连续之字；pause 段计入抬笔时间。

### v1.3：像人一样画、按段配音

- **分镜先算预算。** `storyboard.json` 写镜头与视觉元素，`storyboard_lint.py --budget` 按真实旁白算出需要几个视觉、每个能画几秒、复杂度上限（约每秒3.5笔），图按预算设计，不是画完再压缩时间。
- **两种绘制方式。** 有墨线轮廓、平涂上色的画风（库内 1、4、5、17、19、20）逐笔绘制：整笔描线、先主后次、右手顺序、抬笔移动、马克笔之字形上色；其他画风用揭示：手带宽软笔刷按部位斜向扫出原图。画风选择器标明每种画风的方式，`style/resolved.json` 的 `drawing_mode` 必须与任务一致。
- **汉字按标准笔顺书写**（GB2312 内的字，数据来自 hanzi-writer-data），其余字符按字形描线。
- **旁白按语义段落生成。** 每段不超过约100字、只在句末切，逐段过噪声门禁（嗡声、底噪、削波）和语速 / ASR 检查，不通过换种子重试；拼接停顿实测，自动写 `alignment.json`。改稿时只重生成文字变了的段落，其余已通过的段落直接复用（分段位置不变时）。
- **声音目录。** 逼真男声、逼真女声（本机原片参考）＋四款随包合成声音（磁性解说男声为默认），可添加声明授权的自定义声音。
- **交付。** `verify` 增加声音门禁和字幕同步检查；成片写入 AIGC 隐式标识元数据，发布时仍须在平台声明“AI 生成”。

### v1.2：整篇声音优先

整篇生成/录制并核对旁白后锁定母带，画面和字幕读取母带时间戳。生产构建拒绝逐页音频拼接、固定换图静音、裁换气和变速；验证母带与时间戳哈希，并逐样本检查主体旁白保持完整。详见 `references/continuous-narration.md`。

### v1.2：指定原片音色与纯旁白修复

原片音色不再以合成试听继续克隆。导入参考与逐字稿绑定哈希，VoxCPM2 默认同时使用原参考和准确逐字稿；本机已验收的主力音色保存在个人声音目录中，不进入公共包。参考清理、同文对照、正文短样和完整旁白分别验收；没有附加配乐不代表旁白内部没有杂音。

字幕默认白字黑边，禁止重复字幕；编辑用字幕独立放在 `outputs/editing/`。v1.3 起手部、画风预览与试听随包提供，缺失或损坏时按镜像修复，见[托管与缓存](references/hosted-assets.md)。当前女声暂用，保留原片参考，后续继续调整；不是最终听感验收。
